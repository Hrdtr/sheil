Sheil

Open-source, cross-platform SSH client with an embedded local AI engine for command generation and auto-completion.

Download GitHub

Features

  • Connection management

    Secure connections with key and password authentication, organized with groups and tags.

  • Tab-based sessions

    Every tab is an active session with real-time state management.

  • SFTP file browser

    Integrated file management with drag-and-drop upload and download.

  • Port forwarding

    Local, remote, and dynamic (SOCKS) port forwarding built in.

  • Encrypted credentials

    Passwords and SSH keys encrypted at rest with AES-256-GCM.

  • SSH key management

    Import, store, and manage SSH keys with passphrase support.

  • Local AI engine

    Embedded llama.cpp generates terminal commands and provides ghost-text completion — fully offline.
