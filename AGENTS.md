# AGENTS.md — AI Coding Agent Guide for Sheil

## Project Overview

Sheil is an open-source, cross-platform tool for managing remote and device connections, built with **Tauri 2** (Rust backend) and **Nuxt 4 / Vue 3** (TypeScript frontend). It features an embedded local AI engine (llama.cpp) for terminal command generation and auto-completion, SFTP file management, port forwarding, and encrypted credential storage.

## Architecture

```

│  ├── composables/   Reactive state & business logic     │
│  └── utils/         Tauri IPC wrappers (commands.ts)    │
├─────────────────────────────────────────────────────────┤
│  Tauri IPC Bridge  (invoke / events)                    │
├─────────────────────────────────────────────────────────┤
│  Tauri 2 / Rust Backend                                 │
│  ├── commands/      IPC command handlers (ssh, sftp,    │
│  │                  hosts, port_forward, ai)            │
│  ├── db.rs          SQLite init + migrations (sqlx)     │
│  ├── crypto.rs      AES-256-GCM encrypt/decrypt         │
│  ├── secrets.rs     Credential store/retrieve/delete    │
│  └── lib.rs         App setup, state registration       │
└─────────────────────────────────────────────────────────┘
```

### Key Design Decisions

- **SPA mode**: `ssr: false` in `nuxt.config.ts`. The app runs exclusively inside the Tauri webview.
- **Every tab is a session**: There is no tab without an SSH session. Closing a tab disconnects the session.
- **Single shared composable state**: Composables like `useSessions`, `useSettings`, `useHosts` use Nuxt's `useState` and are wrapped with `createSharedComposable` so state is globally shared.
- **IPC pattern**: Frontend calls Rust via `invoke()` (defined in `app/utils/commands.ts`). Rust emits events to the frontend via `tauri::Emitter`.
- **Encrypted credentials**: Host passwords and SSH key passphrases are encrypted with AES-256-GCM using a master key stored on disk. The `credential` table uses a `service` key namespace.
- **UUIDv7 primary keys**: Time-ordered, index-friendly IDs generated by `db::new_table_row_id()`.

## Coding Conventions

### TypeScript / Vue

- **Single quotes** for strings (enforced by oxfmt).
- **No `console.log`** — only `console.error`, `console.info`, `console.trace`, `console.warn`, `console.time`, `console.timeEnd` are allowed.
- **No `any`** — `typescript/no-explicit-any` is an error.
- **Composable naming**: `use-<feature>.ts` exporting a default function `_use<Feature>()` wrapped with `createSharedComposable` when global state is needed.
- **Component naming**: kebab-case filenames (`quick-connect-dialog.vue`), PascalCase usage in templates.
- **IPC wrappers**: All `invoke()` calls are centralized in `app/utils/commands.ts` with full TypeScript types. Never call `invoke()` directly from components or composables.
- **Import sorting**: Enforced by oxfmt with specific group ordering (type imports → builtins → external → internal → parent → sibling → index).

### Rust

- **Edition 2021**, MSRV 1.77.2.
- **Error handling**: Commands return `Result<T, String>`. Use `.map_err(|e| format!("...: {e}"))` for error conversion.
- **State management**: Shared state is registered via `app.manage()` in `lib.rs` and accessed in commands via `State<'_, T>`.
- **Async**: All I/O is async via tokio. Use `tokio::sync::Mutex` for shared mutable state (not `std::sync::Mutex`).
- **Database**: SQLx with compile-time checked queries is NOT used — queries are runtime-checked. Migrations live in `tauri/migrations/` as chronological SQL files.
- **Naming**: snake_case for functions/variables, PascalCase for types/structs.
- **Doc comments**: Use `///` for public items.

### Commits

Conventional Commits format enforced by commitlint:

```
<type>: <description>

Types: feat, fix, docs, chore, style, refactor, ci, test, revert, perf, build
```

All commits must be DCO signed-off (`git commit -s`).

## Key Patterns

### Adding a New Tauri Command

1. **Rust**: Add the `#[command]` function in the appropriate file under `tauri/src/commands/`.
2. **Rust**: Register it in `tauri/src/lib.rs` in the `invoke_handler(tauri::generate_handler![...])` list.
3. **TypeScript**: Add the typed wrapper in `app/utils/commands.ts` under the appropriate namespace (`host`, `ssh`, `sftp`, `portForward`, `ai`).
4. **TypeScript**: Call it from a composable or component via `commands.<namespace>.<method>()`.

### Adding a New Composable

1. Create `app/composables/use-<feature>.ts`.
2. Define the function as `function _use<Feature>() { ... }`.
3. If global state is needed, export as `export const use<Feature> = createSharedComposable(_use<Feature>)`.
4. Use `useState<T>('key', () => initialValue)` for reactive shared state.

### Adding a New Database Table

1. Create a new migration file in `tauri/migrations/` with the format `YYYYMMDDHHMMSS_description.sql`.
2. Use `TEXT` for UUIDs, `TEXT` for timestamps with `datetime('now')` defaults.
3. Add indexes for frequently queried columns.
4. Access via `sqlx::query()` in the appropriate command module.

### Credential Storage

- Host passwords: service key `sheil.host.<host_id>`
- SSH key passphrases: service key `dev.hrdtr.sheil.ssh_key.<key_name>.passphrase`
- SSH private keys: service key `dev.hrdtr.sheil.ssh_key.<key_name>` (encrypted and stored in SQLite)
- All SQLite credentials encrypted with AES-256-GCM via `secrets::store()` / `secrets::retrieve()`.

### Frontend Event Handling

Rust emits events to the frontend via `window.emit("event://name", payload)`. The frontend listens with `listen()` from `@tauri-apps/api/event`. Example: AI download progress uses `ai://download-progress`.

## Important Constraints

- **No server-side rendering**: `ssr: false`. Do not use Nuxt server features (server routes, server middleware, etc.).
- **No direct `invoke` calls**: Always go through `app/utils/commands.ts`.
- **No editing `app/components/ui/`**: These are generated UI component files.
- **Formatter ignores**: `tauri/gen/**` and `app/components/ui/**` are excluded from oxfmt and oxlint.
- **Node.js >= 24.17.0** required (specified in `package.json` engines).
- **xterm.js data conversion**: `Uint8Array` must be converted to `number[]` via `Array.from()` before passing to `invoke()` (Tauri IPC does not support typed arrays directly).
- **Terminal focus management**: The `use-terminal-focus` composable provides a shared registry of live xterm instances, allowing decoupled UI (e.g. AI command palette) to focus the active terminal.

## Testing

- **Rust tests**: `cargo test --manifest-path tauri/Cargo.toml` (or `pnpm run test`).
- **In-memory test DB**: Use `db::test_pool()` for tests that need SQLite — creates an in-memory pool with all migrations applied.
- **Test fixtures**: Located in `tauri/tests/fixtures/`.
- **No frontend test framework** is currently configured.

## Security Notes

- Credentials are encrypted at rest with AES-256-GCM.
- The master encryption key is generated once and stored in the app data directory.
- SSH private keys are encrypted with AES-256-GCM and stored in the SQLite database.
- The app disables the right-click context menu globally except on inputs/textareas.
- CSP is set to `null` in `tauri.conf.json` (permissive — Tauri IPC requires it).
